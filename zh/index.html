DeepSeek Harness Plugins

by Yishan

为 DeepSeek Harness Web UI 与 CLI 设计的四款专注插件：追踪 Token 消耗与活动热图、回放 Agent 工具调用时序、在 Web Audio 律动工作站中编曲，以及使用原生输入法练习打字。

  • 01v1.4.1 dsh-burn 四类 Token 构成、活动热图与多 Provider 计价
  • 02v0.1.0 dsh-sequence 每轮工具调用时序图与动画回放
  • 03v1.3.0 dsh-synthesizer Web Audio 多轨合成器与口袋律动工作站
  • 04v0.2.0 dsh-typing-practice 原生输入法打字练习与落词游戏
01 · 用量与可观测 v1.4.1 yishan/dsh-burn

dsh-burn

DeepSeek Harness 的用量与余额看板。仅统计会话自身新增用量（排除继承前缀），将 Token 折叠为四项互不重叠的构成，使用本地 ECharts SVG 渲染日历、星期×小时与 Provider 热图，并支持多路由定价与余额追踪。

dsh plugin add github:yishan/dsh-burn
02 · 轨迹检查 v0.1.0 yishan/dsh-sequence

dsh-sequence

对话内每轮 Agent 工具调用时序图与动画回放插件。将 DSH 轨迹事件流编译为确定性 SVG 泳道图，支持并行调用分组、错误与重试标记、慢调用标识，以及一键导出独立 SVG 或可回放 HTML。

dsh plugin add dsh-sequence
03 · 音频合成 v1.3.0 yishan/dsh-synthesizer

dsh-synthesizer

DeepSeek Harness 里的多轨合成器与口袋律动工作站。在钢琴卷帘或 8 件套鼓机步进器上编曲，通过实时 Web Audio 减法合成器塑形音色并循环播放；切回对话后音乐继续在后台响起，工程保存于当前 profile。

dsh plugin add github:yishan/dsh-synthesizer
04 · 打字练习 v0.2.0 yishan/dsh-typing-practice

dsh-typing-practice

DeepSeek Harness 内的英文、简体中文与粤语打字练习及落词游戏。直接使用系统原生输入法，内置拼音、双拼与粤拼提示词典，并附带机械键盘音效包与本地成绩记录。

dsh plugin add dsh-typing-practice
