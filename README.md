# DeepSeek Harness Plugins

Single-page introduction for DeepSeek Harness (DSH) plugins by [Yishan](https://yishan.li).

## Included Plugins

- **[dsh-burn](https://github.com/yishan/dsh-burn)** — Usage & balance dashboard: owned-scope token folding, calendar/weekday-hour/provider heatmaps, multi-provider pricing, and CSV export.
- **[dsh-sequence](https://github.com/yishan/dsh-sequence)** — In-conversation per-turn agent tool-call sequence diagram, timeline, and animated playback.
- **[dsh-synthesizer](https://github.com/yishan/dsh-synthesizer)** — Multi-track browser synthesizer and pocket groovebox with a real-time Web Audio subtractive engine.
- **[dsh-typing-practice](https://github.com/yishan/dsh-typing-practice)** — Typing practice and falling-words game with native IME support, Pinyin/Jyutping hints, and mechanical keyboard sound packs.
