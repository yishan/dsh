DeepSeek Harness Plugins

by Yishan

Four focused plugins for the DeepSeek Harness Web UI and CLI: track token spend and activity heatmaps, replay agent tool-call sequences, sketch loops on a Web Audio groovebox, and practice typing with your native IME.

  • 01v1.4.1 dsh-burn Token buckets, heatmaps & multi-provider cost
  • 02v0.1.0 dsh-sequence Per-turn tool-call sequence & replay
  • 03v1.3.0 dsh-synthesizer Multi-track Web Audio groovebox
  • 04v0.2.0 dsh-typing-practice Native-IME typing & falling words
01 · OBSERVABILITY v1.4.1 yishan/dsh-burn

dsh-burn

Usage and cost dashboard for DeepSeek Harness. Folds owned session usage into four non-overlapping token buckets, renders calendar, weekday-hour, and provider heatmaps with local ECharts SVG, and tracks multi-provider pricing and account balances.

dsh plugin add github:yishan/dsh-burn
02 · INSPECTION v0.1.0 yishan/dsh-sequence

dsh-sequence

In-conversation per-turn agent tool-call sequence diagram and animated playback. Compiles DSH trajectory events into deterministic SVG swimlanes with parallel groups, error/retry markers, slow-call badges, and one-click HTML export.

dsh plugin add dsh-sequence
03 · AUDIO v1.3.0 yishan/dsh-synthesizer

dsh-synthesizer

Multi-track browser synthesizer and pocket groovebox inside DeepSeek Harness. Sketch melodies on a piano roll or 8-piece drum stepper, sculpt tone with a real-time Web Audio subtractive engine, and keep loops playing in the background while you chat.

dsh plugin add github:yishan/dsh-synthesizer
04 · PRACTICE v0.2.0 yishan/dsh-typing-practice

dsh-typing-practice

Typing practice and falling-words game in DeepSeek Harness for English, Simplified Chinese, and Cantonese. Supports your own OS input method with bundled Pinyin, Shuangpin, and Jyutping hints, plus mechanical keyboard sound packs.

dsh plugin add dsh-typing-practice
